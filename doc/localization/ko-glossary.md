# Korean UI glossary

This glossary is normative for the Korean UI. Keep API values, identifiers, model names,
provider names, environment variable names, paths, commands, and code snippets unchanged.

## Translation rules

- Translate only user-facing UI copy. Do not translate data received from the server.
- Preserve `{{count}}`, `{{name}}`, `%s`, and other placeholders exactly.
- Preserve HTML tags, Markdown link targets, URLs, punctuation that carries meaning, and keyboard shortcuts.
- Keep buttons short. Translate descriptions naturally for meaning and context rather than word-for-word.
- Preserve the meaning of numbers, dates, plural forms, status labels, warnings, and error messages.
- Use English as the source and fallback language. A Korean key must have a matching English key.
